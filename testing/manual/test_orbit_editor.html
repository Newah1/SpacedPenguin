Orbit Editor Test

Instructions:

  • Click "Toggle Level Editor" to enter edit mode
  • Click "Add Orbiting Bonus" to add a bonus with circular orbit
  • Click "Add Planet" to add a central planet
  • In edit mode, you can drag the orange orbit center indicators
  • You can also drag the objects themselves
  • Select objects to edit their orbit properties in the properties panel
  • Use the "Clone Selected" button to duplicate objects
  • View and select objects from the object list panel (bottom left)
